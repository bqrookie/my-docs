没问题！钣金展开计算是折弯工艺的核心。你提到的“铁板1.6、不锈钢1.7乘以板厚”，在行业内通常被称为**折弯扣除（Bend Deduction, BD）**，这是工厂现场算料最常用、最高效的方法。

我为你整理了钣金展开计算中最常用的核心公式、K因子以及不同材质的折弯扣除速查表。你可以直接保存到你的MD笔记中：

### 1. 展开长度核心公式
*   **折弯扣除法（现场算料首选）**：展开长度 = 折弯边A外尺寸 + 折弯边B外尺寸 - 折弯扣除值
*   **K因子法（3D建模首选）**：展开长度 = 直边A内尺寸 + 直边B内尺寸 + 折弯补偿弧长（BA）

### 2. 常用材质 90°折弯扣除速查表（BD ≈ 系数 × 板厚T）
这是工厂里最常用的经验数据（通常默认内R角≈1倍板厚，下模槽宽≈6~8倍板厚）：

| 材质类型 | 90°折弯扣除经验系数 | 展开公式（90°） | 备注说明 |
| :--- | :--- | :--- | :--- |
| **冷轧钢板(SPCC/Q235)** | 1.6 ~ 1.7 | 展开 = A + B - 1.7T | 最常用，薄板(≤3mm)取1.7，厚板(>3mm)取1.6 |
| **不锈钢(SUS304)** | 1.7 ~ 1.8 | 展开 = A + B - 1.7T | 硬度高、回弹大，折弯扣除比铁板大0.1~0.2 |
| **铝板(AL 5052/6061)** | 1.5 ~ 1.6 | 展开 = A + B - 1.6T | 延展性好，拉伸量小，系数整体比铁板小 |
| **铜板(CU)** | 1.6 ~ 1.7 | 展开 = A + B - 1.65T | 介于铁板和铝板之间，更偏近铝板 |

### 3. 特殊角度与工艺的经验扣除系数
除了标准的90度折弯，实际生产中还会遇到以下情况：

| 折弯类型 / 角度 | 经验扣除系数 | 展开公式 | 适用场景 |
| :--- | :--- | :--- | :--- |
| **135° 钝角折弯** | 0.5T | 展开 = A + B - 0.5T | 仅适用于135度钝角 |
| **压死边 (褶边)** | 0.4T | 展开 = 直边 - 0.4T | 将边缘压平贴合的工艺 |
| **180° 折返边** | 0.5T | 展开 = A + B - 0.5T | 边缘对折 |
| **非90°通用换算** | 按比例折算 | 扣除值 = 90°扣除值 × (实际角度/90°) | 仅适用于折角≥30°的情况 |

### 4. 3D建模专用：K因子参考值
如果你在SolidWorks等软件中画图，软件需要输入K因子（中性层位置）来计算。以下是行业通用默认值：

*   **冷轧碳钢 (SPCC)**：K = 0.40（新手不确定时默认填0.4，误差可控）
*   **不锈钢 (SUS304)**：K = 0.38（硬度高，中性层偏移量大）
*   **铝合金 (5052/6061)**：K = 0.43（塑性好，中性层更靠近板材中间）
*   **紫铜/黄铜**：K = 0.45（塑性最好，大R角时接近0.5）

### 💡 实战避坑指南
1.  **厚板差异缩小**：当板厚超过 3.0mm 后，铁板、铝板、不锈钢的折弯系数会趋于一致，因为厚板的刚性开始占主导。
2.  **R角变大时**：如果铝板折弯要求内R角大于1mm，需要相应加大折弯系数。
3.  **试折校准**：以上所有系数都是“经验参考值”。不同厂家的折弯机、模具磨损程度都会影响尺寸。**高精度要求的产品，批量生产前一定要先试折一两件，实测尺寸后再微调系数**。
