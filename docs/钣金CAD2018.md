# 🛠️ 折弯方向 CAD 精选学习路线

## 第一阶段：AutoCAD 核心操作（3-5天）
> 💡 目标：掌握展开图绘制所需的最小命令集，跳过所有无关的机械制图内容。

- [ ] **第01讲**：功能优化, 基础操作, 直线画法, 标注
  - *理由*：展开图绘制的核心操作，90%的钣金展开图靠这5个命令完成。
- [ ] **第02讲**：直线画图实例、快速标注技法应用
  - *理由*：展开图绘制的核心操作，90%的钣金展开图靠这5个命令完成。
- [ ] **第03讲**：斜线画法, 标注应用
  - *理由*：展开图绘制的核心操作，90%的钣金展开图靠这5个命令完成。
- [ ] **第04讲**：直线综合实例讲解
  - *理由*：展开图绘制的核心操作，90%的钣金展开图靠这5个命令完成。
- [ ] **第05讲**：偏移、旋转、移动、复制应用技法
  - *理由*：展开图绘制的核心操作，90%的钣金展开图靠这5个命令完成。
- [ ] **第09讲**：圆，圆角，打断及定位线
  - *理由*：折弯R角对应展开图中的圆弧；定位线是折弯基准线的画法基础。
- [ ] **第10讲**：复制、切线、圆应用及制图实例
  - *理由*：多段折弯件的展开需要精确相切关系，避免展开后尺寸累积误差。
- [ ] **第17讲**：镜像技法高效实例讲解
  - *理由*：对称钣金件只需画一半再镜像，效率翻倍且保证对称精度。
- [ ] **第39讲**：标注样式应用详细讲解
  - *理由*：⚠️ 选看：仅在需要出正式检验图纸时调整公差标注样式，日常内部展开图可不学。
- [ ] **第42讲**：图层-对象格式应用
  - *理由*：🔴 工艺核心：数控折弯机通过图层区分轮廓线/折弯线/中心线，图层错了机器无法识别。
- [ ] **第43讲**：投影视图画法及实例讲解1
  - *理由*：读懂三视图才能判断折弯方向、折弯顺序，这是从"画图"到"懂工艺"的桥梁。
- [ ] **第45讲**：投影视图画法及实例讲解2
  - *理由*：读懂三视图才能判断折弯方向、折弯顺序，这是从"画图"到"懂工艺"的桥梁。

## 第二阶段：机械制图·钣金子集（2-3周）
> 💡 目标：只学跟钣金有关的识图知识，跳过齿轮、螺纹等无关内容。

- [ ] **三视图投影规律** (🔴 最高优先级)
  - *内容*：主/俯/左视图对应关系、第一角vs第三角投影法。
  - *关联*：看懂客户图纸的折弯方向和位置，避免折反。
- [ ] **剖面图与局部放大** (🔴 最高优先级)
  - *内容*：全剖、半剖、阶梯剖、局部放大图画法。
  - *关联*：理解板材截面结构、折弯R角细节、焊接坡口。
- [ ] **尺寸标注规范** (🔴 最高优先级)
  - *内容*：基准选择、公差标注、表面粗糙度符号。
  - *关联*：判断哪些尺寸是关键控制尺寸，哪些是自由公差。
- [ ] **钣金专用符号** (🟡 高优先级)
  - *内容*：折弯线符号、展开标注、板材厚度标注惯例。
  - *关联*：直接对接车间生产语言。
- [ ] **装配图基础** (🟢 低优先级)
  - *内容*：配合关系、装配顺序。
  - *关联*：理解折弯件在整机中的安装位置，预判干涉风险。

## 第三阶段：过渡衔接验证（1周）
> 💡 目标：用手工计算验证CAD绘图，确保进入SW前逻辑闭环。

- [ ] **找一张真实折弯件工程图**
  - *要求*：带三视图 + 完整尺寸标注。
- [ ] **手工计算展开尺寸**
  - *方法*：使用K因子或折弯扣除公式（参考速查表）。
- [ ] **用AutoCAD画出展开图并标注**
  - *要求*：严格按照手算结果绘制，不依赖软件自动展开。
- [ ] **车间师傅验证偏差**
  - *标准*：偏差 ≤ ±0.5mm。
  - *结果*：✅ 通过 → 进入SW；❌ 未通过 → 回头补展开计算。

## 第四阶段：SolidWorks 钣金模块（2-3周）
> 💡 目标：将二维思维转化为三维参数化建模。

- [ ] **基体法兰**
  - *内容*：钣金基础特征创建（SW钣金建模的起点）。
- [ ] **边线法兰**
  - *内容*：折弯边生成与参数设置（对应实际折弯工序）。
- [ ] **斜接法兰**
  - *内容*：多段连续折弯建模（箱体类零件核心功能）。
- [ ] **展开/折叠**
  - *内容*：展开图生成与导出（对接数控编程的前置步骤）。
- [ ] **钣金切割清单**
  - *内容*：BOM表与下料清单生成（生产备料依据）。
- [ ] **K因子/折弯扣除设置**
  - *内容*：材料参数校准（用第二阶段手算经验验证软件默认值）。
